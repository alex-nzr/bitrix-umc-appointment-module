# ADR 0001: изоляция 1С за SDK gateway

## Контекст

Формат SOAP-запросов и ответов 1С не должен распространяться в контроллеры, репозитории и frontend. Эти слои работают с данными клиник, сотрудников, услуг и записей.

## Решение

Интеграция размещена в `Integration\UmcSdk\Gateway\Sdk`, который реализует `UmcGatewayInterface`, использует `BitUmcClient`, валидаторы и mapper’ы DTO. Прикладные сценарии зависят от gateway через `Service\Exchange\Manager`.

## Последствия

Изменение транспорта или формата 1С локализуется в интеграционном слое. Для новых операций требуется добавить контракт SDK и явный маппинг, а не передавать сырые массивы через контроллер.
