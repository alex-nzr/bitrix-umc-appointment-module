# ADR 0002: кеш с блокировкой обновления

## Контекст

Справочники и расписание могут одновременно запросить несколько посетителей. Параллельные одинаковые вызовы к 1С создают лишнюю нагрузку и могут вернуть несогласованные результаты.

## Решение

`Gateway\Sdk` хранит данные в `CacheProvider` и использует отдельный ключ блокировки для каждого набора параметров. Запрос, увидевший блокировку, ждёт появления кеша ограниченное время.

## Последствия

Основной поток избегает дублирующих запросов к 1С. Ключ блокировки должен освобождаться в `finally`; при добавлении нового кешируемого метода следует использовать тот же паттерн.
