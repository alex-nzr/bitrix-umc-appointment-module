# ADR 0003: шифрование секретов ключом ядра Битрикс

## Контекст

Учётные данные SOAP и токен не должны быть защищены предсказуемым ключом, встроенным в код модуля.

## Решение

`Service\Security\Encryptor` шифрует новые значения форматом `v2:` через `Bitrix\Main\Security\Cipher` и `crypto_key` конфигурации ядра Битрикс. Legacy-миграция размещена только в release-updater и не является частью runtime-модуля.

## Последствия

Рабочая версия модуля не расшифровывает старый формат. Updater обязан корректно мигрировать значения при обновлении; код приложения не должен возвращать legacy-поддержку.
